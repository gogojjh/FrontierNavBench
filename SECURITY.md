# Security policy

Do not include credentials or confidential datasets in a public issue.

Report security issues privately through
[GitHub private vulnerability reporting](https://github.com/gogojjh/vnav_benchmark/security/advisories/new)
when that feature is enabled. Otherwise use a private contact method listed on
the [maintainer's profile](https://github.com/gogojjh), or open an issue asking
for a private reporting channel without disclosing the vulnerability itself.

Include the affected commit, a minimal reproduction and the impact. Remove
tokens, private URLs, raw camera recordings and personal data from attachments.

Security fixes target the current source release; older research snapshots are
not maintained as separate security branches. This project has no guaranteed
response-time or long-term-support commitment.
