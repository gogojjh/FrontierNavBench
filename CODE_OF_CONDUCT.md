# Code of conduct

Treat contributors and users respectfully. Review technical ideas on their
merits, explain disagreements constructively and respect people's privacy.
Harassment, threats, discriminatory abuse and publishing private information
are unacceptable in issues, pull requests and other project spaces.

Maintainers may remove abusive content or restrict participation. Concerns can
be reported to [the repository maintainer](https://github.com/gogojjh) using a
private contact method on their profile. Do not post personal details publicly.
